從 0 開始學 K-map

這份教材的目標不是讓學生背公式，而是讓學生理解：K-map 是把 Truth Table 變成可視化群組，再把群組轉回可維護的邏輯式與 PLC 程式。換句話說，K-map 是「數學正確」走向「工程可用」的轉接頭。

本頁範例

三個輸入 A、B、C。當至少兩個輸入為 ON 時，OUT = 1。這是 K-map 入門最好的範例之一：足夠簡單，但又能看出化簡的價值。

目標結果：
OUT = AB + AC + BC
SCL：#OUT := (#A AND #B) OR (#A AND #C) OR (#B AND #C);

FAQ

常見問題
Q1：K-map 是不是一開始就要教？

不是。K-map 應該放在 Truth Table 之後。學生必須先知道所有輸入組合與輸出結果，K-map 才有意義。否則只是畫格子，不是在建模。

Q2：為什麼 K-map 的欄位是 00、01、11、10？

因為這是 Gray Code，相鄰欄位只差一個 bit。K-map 的群組成立，是因為相鄰格只有一個變數改變，因此可以消去該變數。

Q3：K-map 什麼時候不好用？

當問題有時間順序、記憶、步驟、互鎖、延遲、邊緣觸發時，K-map 就不是主工具。這些問題應該轉向 FSM、Latch、Timer 或狀態表。

Q4：K-map 和 PLC SCL 的關係是什麼？

K-map 負責把組合邏輯化簡，SCL 負責把化簡後的邏輯實作。K-map 不是 PLC 程式，但它能幫助你產生更清楚、更可維護的 SCL 條件式。

練習題

Practice

練習 1：任兩個以上 ON

A、B、C 中至少兩個為 ON，OUT = 1。請寫出 Truth Table、SOP、化簡式與 SCL。

OUT = AB + AC + BC
#OUT := (#A AND #B) OR (#A AND #C) OR (#B AND #C);

練習 2：奇數個 ON

A、B、C 中有奇數個為 ON，OUT = 1。觀察 K-map 是否容易形成大群組。

OUT = A XOR B XOR C
這題不是典型 AND-OR 化簡題，而是 Parity / XOR 結構。

練習 3：A 優先

若 A=1 則 OUT=1；若 A=0，再由 B 與 C 決定。這題是否適合 K-map？

可以用 K-map 化簡，但教學上更應引導學生看到 Priority 結構。若規則有明確優先順序，SCL 常用 IF / ELSIF 表達。

練習 4：按下 Start 後保持輸出

Start 按下後 OUT 保持 ON，Stop 按下後 OUT OFF。這題能用 K-map 嗎？

不適合只用 K-map，因為這題有記憶。應使用 Latch 或 FSM。這是組合邏輯與循序邏輯的分界題。
